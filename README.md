# Turkish Remote Jobs

A beginner-friendly MVP for discovering remote work opportunities relevant to Turkish-speaking job seekers and people living in Turkey.

This project is intentionally built as a clean, mobile-friendly starter with sample data clearly marked as demo content. It is designed to be easy to extend as the project grows.

## Project goals

- Showcase a modern homepage for remote job discovery
- Provide search and filtering for roles relevant to Turkish-speaking candidates
- Highlight eligibility for residents of Turkey
- Label referral links and sample data clearly
- Keep the code structure simple and maintainable

## Tech stack

- React
- Vite
- TypeScript
- CSS

## Getting started

```bash
npm install
npm run dev
```

Then open the local URL displayed in the terminal.

## Project structure

```text
src/
  components/
  data/
  App.tsx
  index.css
  main.tsx
```

## Notes

- Job listings in this MVP are sample data only.
- Compensation, eligibility, and application details are placeholders for development and design review.
- Replace the sample dataset and content with real, verified listings as the project grows.
